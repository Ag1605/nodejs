HTTP Methods in Node.js
HTTP methods define what action the client wants the server to perform on a resource.

For example, suppose you are building a user management application.

Get all users.

Create a new user.

Update an existing user.

Delete a user.

We use different HTTP methods for these operations.

1. Types of HTTP Methods
There are five important HTTP methods you should understand.

GET
Retrieve data

Example: Get all users

POST
Create new data

Example: Register a user

PUT
Replace existing data

Example: Replace a user's complete profile

PATCH
Partially update data

Example: Change only the user's name

DELETE
Delete existing data

Example: Delete a user

2. Understand with a real-life example
